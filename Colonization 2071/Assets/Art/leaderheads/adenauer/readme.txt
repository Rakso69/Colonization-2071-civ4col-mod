Konrad Adenauer For Civ4
================================================================================
From all i know, the files will work with Vanilla and Warlords. However
only BTS was actually tested. 

Installation
================================================================================
This is not a playable Mod, just artwork.

My Art-Define for him:

<LeaderheadArtInfo>
  <Type>ART_DEF_LEADER_ADENAUER</Type>
  <Button>Art/LeaderHeads/Adenauer/Chancelor_button.dds</Button>
  <NIF>art/LeaderHeads/Adenauer/Chancelor.nif</NIF>
  <KFM>art/LeaderHeads/Adenauer/Chancelor.kfm</KFM>
  <NoShaderNIF>art/LeaderHeads/Adenauer/Chancelor_Noshader.nif</NoShaderNIF>
  <BackgroundKFM>art/LeaderHeads/Adenauer/Chancelor_bg.kfm</BackgroundKFM>
</LeaderheadArtInfo>

You can find tutorials and information about adding stuff to the game at 
CivFanatics. http://forums.civfanatics.com/forumdisplay.php?f=177
