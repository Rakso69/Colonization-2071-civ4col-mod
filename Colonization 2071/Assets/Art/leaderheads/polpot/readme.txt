PolPot For Civ4
================================================================================
From all i know, the files will work with Vanilla and Warlords. However
only BTS was actually tested. 

Installation
================================================================================
This is not a playable Mod, just artwork.

My Art-Define for him:

<LeaderheadArtInfo>
   <Type>ART_DEF_LEADER_POLPOT</Type>
   <Button>Art/LeaderHeads/PolPot/PolPot_button.dds</Button>
   <NIF>art/LeaderHeads/PolPot/PolPot.nif</NIF>
   <KFM>art/LeaderHeads/PolPot/PolPot.kfm</KFM>
   <NoShaderNIF>art/LeaderHeads/PolPot/PolPot_Nonshader.nif</NoShaderNIF>
   <BackgroundKFM>art/LeaderHeads/PolPot/PolPot_bg.kfm</BackgroundKFM>
</LeaderheadArtInfo>

You can find tutorials and information about adding stuff to the game at 
CivFanatics. http://forums.civfanatics.com/forumdisplay.php?f=177
