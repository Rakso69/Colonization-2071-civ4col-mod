Network Node
============

The network node is a combination of communications hub and a huge network server. Similar to the way a wireless router worked on a home scale in the early 21st century, this hub handles the entire wireless network traffic within an entire city. It not only allows lightning fast connection to the main computer facilities from any wireless device within the broadcasting radius, but it also connects devices among each other for personal communication.

Inspired by the SMAC facility and made for the Planetfall team.

Recommended fScale = 1.5; fInterfaceScale = 0.4; model has 281 polys.
